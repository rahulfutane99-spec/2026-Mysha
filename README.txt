SHAMAL BIRTHDAY SURPRISE WEBSITE

This is a fresh 5-page romantic pink website for Rahul and Shamal.

PAGES: index.html, memories.html, quiz.html, letter.html, surprise.html
GALLERY: Six clear, full-size photos. Tap any photo to open it. The full image is shown without cropping.
MUSIC: birthday-melody.wav (tap the music button to play).
QUIZ: Seven questions. Question 2 asks the first unofficial date/meeting; the correct answer is 22 February.

IMPORTANT GITHUB UPLOAD INSTRUCTIONS:
1. Extract this ZIP on your computer.
2. Open the shamal_birthday_website folder.
3. Select ALL files inside that folder (do not upload only the HTML files).
4. Upload them directly into the ROOT of your new GitHub repository.
5. You should see index.html, memories.html, style.css, memory-1.jpg through memory-6.jpg, birthday-melody.wav and pink-background.png together in the repository root.
6. Commit changes. In GitHub, open Settings > Pages and publish from the main branch, root folder.
7. Wait for deployment, then refresh your website with Ctrl+F5.

All image, music and background paths are root-relative so no assets subfolder is required.
